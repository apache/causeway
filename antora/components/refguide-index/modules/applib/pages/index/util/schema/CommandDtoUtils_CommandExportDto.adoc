Portable command DTO envelope with optional _BookmarkDto result_ metadata.

The YAML representation uses _command_ and _result_ ; the result contains _type_ and _id_ . Unknown input fields are ignored, but the legacy _returnedObject_ name is not an alias for _result_ .

== API

[source,java]
.CommandDtoUtils_CommandExportDto.java
----
class CommandExportDto {
  CommandExportDto of(CommandDto command, Bookmark result)
  CommandDto getCommand()
  void setCommand(CommandDto command)
  BookmarkDto getResult()
  void setResult(BookmarkDto result)
}
----
