Looks up replay command inputs before execution and observes replay result bookmark mappings.

----
interface CommandReplayMappingListener {
  Optional<Bookmark> lookup(Bookmark recordedBookmark)     // <.>
  void onReplayResult(Bookmark recordedResult, Bookmark actualResult, UUID interactionId)     // <.>
}
----
