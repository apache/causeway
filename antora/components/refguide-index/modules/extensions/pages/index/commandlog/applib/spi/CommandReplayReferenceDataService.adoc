Classifies command replay/export participants that are stable reference data.

Implementations must only return _true_ for bookmarked entities whose logical type and identifier are expected to be stable, well-known, and present in every replay environment. Implementations classify bookmark identity only and must not require the bookmark to have appeared in a command sequence.

Applications may register any number of implementations. A bookmark is reference data when any registered implementation accepts it.
