Classifies bookmarked entities whose logical type and identifier are stable and expected to exist in every command replay environment.

Applications can register zero or more implementations.
Classification uses OR semantics: a bookmark is reference data when any implementation accepts it.
A null bookmark, no services, or no accepting service returns `false`; classifier failures remain visible.

The commandlog module registers `CommandReplayReferenceDataServiceForRefData` by default.
It resolves the bookmark through the metamodel and accepts the corresponding class when it implements `RefData`, without loading or instantiating the bookmarked object.

SecMan's `ApplicationUser`, `ApplicationRole`, `ApplicationTenancy`, and `ApplicationPermission` abstractions implement `RefData`.
Replay deployments therefore need to provision matching SecMan identities in every environment.

Reference-data classification alone does not change exportability or command-manager collections.
Known-participant and reachability integration is provided by the later export-reachability capability.

== API

[source,java]
.CommandReplayReferenceDataService.java
----
interface CommandReplayReferenceDataService {
  boolean isReferenceData(Bookmark bookmark);

  static boolean isReferenceData(
      List<? extends CommandReplayReferenceDataService> services,
      Bookmark bookmark);
}
