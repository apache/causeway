The unified command manager is the primary commandlog surface for reviewing foreground command sequences.
It is a command-recording-suppressed view model whose bookmark state contains an inclusive baseline timestamp and a page limit, which defaults to 100.

The manager provides four read-only views:

* `commandsInSequence` shows the bounded, eligible, non-excluded foreground sequence.
* `excluded` shows eligible commands marked `EXCLUDED`.
* `pendingOrFailed` shows every imported command awaiting replay or retry, including resultless safe actions.
* `recordedOrReplayed` shows eligible `UNDEFINED`, legacy `EXPORTED`, and successfully replayed `OK` commands.

Replay or retry is available for commands in `PENDING`, `OK`, and `FAILED` states.
It is unavailable for `UNDEFINED`, `EXPORTED`, and `EXCLUDED` commands.
Background-completion gating is not part of this manager contract.

Existing `CommandExportManager` and `CommandReplayManager` bookmarks remain valid.
Both legacy managers provide a safe `openCommandManager` action that transfers their baseline and uses the default limit.

== API

[source,java]
.CommandManager.java
----
class CommandManager implements ViewModel, HasBaseline, HasLimit, CommandRecordingSuppressed {
  public static final String LOGICAL_TYPE_NAME;
  public static final int DEFAULT_LIMIT;
  Timestamp getBaseline();
  int getLimit();
  List<ReplayableCommand> getCommandsInSequence();
  List<ReplayableCommand> getExcluded();
  List<ReplayableCommand> getPendingOrFailed();
  List<ReplayableCommand> getRecordedOrReplayed();
}
----
