Persistent association between a result bookmark recorded on the source system and the bookmark returned when the command is replayed locally.

== API

[source,java]
.CommandReplayResultMapping.java
----
interface CommandReplayResultMapping {
  String LOGICAL_TYPE_NAME;
  String SCHEMA;
  String TABLE;
  String title()
  void init(Bookmark recordedBookmark, Bookmark actualBookmark, UUID commandInteractionId)
  Bookmark getRecordedBookmark()
  void setRecordedBookmark(Bookmark recordedBookmark)
  Bookmark getActualBookmark()
  void setActualBookmark(Bookmark actualBookmark)
  UUID getCommandInteractionId()
  void setCommandInteractionId(UUID commandInteractionId)
}
----
