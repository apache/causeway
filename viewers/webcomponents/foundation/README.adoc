This module packages framework-neutral ECMAScript modules that consume the Apache Causeway rich GraphQL schema.
The Maven artifact exposes the modules below `META-INF/resources/causeway-webcomponents/` and runs its dependency-free test suite with the Node.js test runner.

The package provides coordinated and standalone application menu bars, service-action interaction adapters, layout-aware composite objects, semantic object headers, read-only and explicitly editable properties, values, object links, action affordances, declarative property- and collection-associated actions, the standard accessible action interaction controller, semantic command execution, editor and renderer extension, normalized action outcomes, lazy collections, declarative collection columns, hydrated row contexts, semantic events, an external structural stylesheet, and an optional cohesive theme.
The default semantic foundation deliberately has no HTMX, React, Vue, Svelte, Wicket, Bootstrap, or eagerly loaded browser component-authoring runtime dependency.
The artifact also contains opt-in route-lazy Vaadin free-core reference and semantic field closures behind the stable Causeway editor contract; applications that do not enable or instantiate a family make no request for its asset.
The packaged `component-styles.css` is the CSP-compatible equivalent of `installCausewayComponentStyles()`, while `theme.css` supplies the Wicket-inspired visual tokens and responsive presentation.
See link:USAGE.adoc[USAGE.adoc] for the public component contracts, application-entry menu coordination, safe effective-menu parsing, service-action prompts and results, standalone bars, effective-grid and fallback object composition, plain-HTML composition, declarative member-associated actions, renderer and editor registration, optional reference and semantic field widgets, property validation and mutation, application overrides, collection activation and row hydration, accessibility and styling classes, semantic events, and current collection-size limitations.
