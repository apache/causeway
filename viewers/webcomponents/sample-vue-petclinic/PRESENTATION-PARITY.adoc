The HTMX Petclinic application is the presentation authority for the Vue Petclinic application.
Parity means equivalent information architecture, declared semantic members, ordering, grouping, responsive relationships, and application theme; framework wrappers and exact rendered pixels need not match.

== Shell baseline

At a wide viewport the shell presents one 3.25rem navigation row with the `C` mark and `Pet Clinic` brand, followed by `Pet Owners`, `Visits`, and the utility grouping defined by the shared `menubars.layout.xml` resource.
The route and footer use one-space-unit side insets, the main region uses the reference vertical spacing, and the footer places `Powered by Apache Causeway` opposite the viewer label.
Document titles use the authoritative object title followed by ` · Pet Clinic`.
Programmatic route focus does not draw a persistent frame around the whole page, while ordinary interactive controls and the skip-link target retain visible keyboard focus.
At widths of 48rem or less shell navigation wraps vertically, and at widths of 60rem or less route grids collapse to one column without horizontal page overflow.

Technical `id` and `version` properties and members not listed above are intentionally absent from the four exact-type pages.
The unregistered `petclinic.ViewerFallback` fixture, with stable identifier `s_viewer-fallback`, demonstrates generic `<cw-object>` fallback independently of those routes.

== Regression strategy

Headless tests assert semantic structure, route boundaries, menu labels, title and footer content, and member declarations for every route.
Computed-style checks use tolerant ranges and relationships for header height, shell inset, grid columns, responsive collapse, focus treatment, and overflow rather than screenshot equality.
Native and Vaadin policies are exercised where toolkit rendering can alter presentation.
