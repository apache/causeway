Coverage guide

States represented here

The explanatory copy describes the fixture; component-rendered state remains the source of truth.

  • Qualified presentationText, multiline, exact and machine numbers, Boolean, enum, local date, local time, and local date-time demonstrate default read-only Vaadin fields, while null and object reference values retain their established renderers.
  • Disabled semanticsCode, object reference, and archive retain explicit reasons supplied by Causeway.
  • Semantic referenceThe related object publishes navigation intent without choosing a URL or router.
  • CollectionsA deterministic wide window qualifies virtual Grid, a disabled sibling preserves its reason, and narrow, empty, and encounter-ordered siblings retain native presentation; use `?grid-mode=bounded` to retain the current window with Causeway previous and next controls and no invented total.
  • Intentionally hiddenThe secret property and hidden action produce no semantic content, and their hidden value is never repeated here.
  • Framework-neutral interactionsOrdinary actions demonstrate the independent Vaadin Button closure, while property interaction controls and prompts remain native and no HTMX, frontend framework, npm build, automatic routing, or component-owned GraphQL construction is present.
  • Rollback and failureUse `?component-toolkit=native`, `?menu-state=empty`, `?menu-state=unsupported`, `?fail-field=basic`, `?fail-action=true`, `?fail-grid=true`, or `?fail-menubar=true` for deterministic empty, unsupported, complete rollback, and family-isolated native recovery states.
