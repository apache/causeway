== Building the Metamodel

Given categories of classes (mixins, values, entities, viewmodels, ...) 
the _Metamodel_ is bootstrapped.  

The internal `SpecificationLoader` shall hold a lookup map, 
containing either a builder or a finished spec. 

[plantuml,fig-introspection-participants,svg]
.Introspection Participants
----
@startuml

object ObjectSpecification {
    facets
    regular members
    mixed-in members
}

class SpecificationLoader <<Service>> {
    loadSpecification(Class): ObjectSpecification
}

hide empty members

@enduml
----
