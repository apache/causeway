# Implementation evidence

## Accepted Menu Bar qualification

Each non-empty representable primary, secondary, or tertiary tier owns one independently qualified internal Menu Bar.
The three semantic tiers remain separate and preserve source order, labels, labeled and unlabeled sections, descriptions, icon hints, hidden actions, disabled actions, bounded disabled reasons, and service-action identity.
Only current enabled leaf descriptors may activate.
Selection resolves an opaque generation-scoped identity and delegates exactly once to the existing Causeway service-action and interaction-controller path.
Menu Bar callbacks do not construct GraphQL, navigate, interpret results, or become public application APIs.

Explicit `causeway.viewer.webcomponents.htmx.component-toolkit=native`, empty tiers, unsupported projections, hidden or disconnected tiers, stale generations, unavailable widths, and family failures use the complete established native presentation or remain hidden.
A family failure returns every connected tier natively while reference, field, action, Grid, GraphQL, route, authentication, and current menu state remain independently operational.
Connected explicit retry rebuilds qualified controls from current authoritative Causeway state.

Container widths at or below 48rem use the accepted Vaadin overflow presentation for representative hierarchies.
Responsive transitions apply outside ResizeObserver delivery, preserve semantic state, and issue no GraphQL reread.
The narrow browser matrices preserve authorized actions, source order, accessible labels, keyboard and pointer operation, Escape dismissal, focus return, and zero page overflow.
If projection or lifecycle qualification cannot preserve those contracts, the complete tier remains native rather than mixing controls.

## Stable-shell delivery and rollback

The authenticated HTMX shell publishes the same-origin Menu Bar closure URL, resolved common component policy, family revision, and bounded diagnostics.
The closure loads only after a non-empty qualified tier connects and is shared across tiers and later stable-shell routes.
Login, authentication challenge, authentication failure, logged-out chrome, empty or unsupported tiers, explicit native mode, and deprecated pilot subsets request no Menu Bar bytes.
Spring Security remains responsible for authentication, sessions, CSRF, request caching, and logout.
Authentication actions owned by shell chrome are excluded before native or toolkit menu projection.

Default and deprecated complete-toolkit compatibility use the deterministic deduplicated exact style-hash union.
Explicit native and deprecated pilot subsets contribute no Menu Bar style hash.
CSP retains `style-src-attr 'none'`, same-origin scripts and connections, no `unsafe-inline`, and no external runtime resources.
Operational rollback requires only `causeway.viewer.webcomponents.htmx.component-toolkit=native` and changes no GraphQL operation, route, persisted data, authentication policy, menu resource, or application markup.
