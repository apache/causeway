# Production isolation verification

No Maven POM, npm package manifest, lock file, dependency version, or third-party package changes are part of this implementation.
No public GraphQL query, mutation, field, argument, scalar, input, output, or generated-name contract changes.
The implementation consumes existing targeted introspection and existing executable fields.

The public `<causeway-*>` vocabulary, context methods, semantic event names, event target details, typed result kinds, canonical routes, HTMX history policy, and browser asset URLs remain unchanged.
The new action dispatch module is an internal same-origin foundation module packaged through the established source-module mechanism.

No Vaadin package, generated bundle, checksum, CSP hash, qualification policy, route-lazy trigger, native fallback, or default-selection property changes.
Routes that do not instantiate an eligible reference editor continue to request no Vaadin candidate bundle.
Action parameters that do instantiate the qualified reference adapter continue to use the same Causeway-owned codec, identity, pending-value, validation, cancellation, and semantic event contracts.

The corrected behavior is rollback-safe because it changes only client operation planning and safe result projection.
Reverting the implementation requires no schema, persisted data, application configuration, route, or asset migration.
